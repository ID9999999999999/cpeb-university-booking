# Evidence

This directory contains supporting proof that the project works as described.

## Structure

| Folder | Purpose |
|---|---|
| `screenshots/` | Visual proof of running components and important workflows |
| `tests/` | Verification summaries and test evidence |
| `logs/` | Build, command and runtime evidence |
| `project-audit/` | Current repository audit snapshot |

## Recommended evidence to review

- `screenshots/approval-flow-test.png` — booking approval workflow.
- `screenshots/equipment-list.png` — equipment/resource data.
- `screenshots/db-health.png` — database connectivity.
- `screenshots/maintenance-booking-block-test.png` — maintenance conflict rule.
- `screenshots/repair-tickets-test.png` — repair workflow.
- `project-audit/CPEB_PROJECT_AUDIT_LATEST.md` — latest preserved audit report.

## Note

Evidence supports the main documentation; it is not the project-status source of truth. For the current state, use [`../docs/PROJECT_STATUS.md`](../docs/PROJECT_STATUS.md).
